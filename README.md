# Spotify-clone
A responsive Spotify Clone built using HTML and CSS only. The project is a static front-end clone that recreates 
the look and feel of Spotify for learning and practice purposes.
## Features
Spotify-inspired UI
Responsive layout
Navigation bar
Sidebar
Music Player UI
## Technologies Used
HTML5
CSS
## Note 
This project is a UI clone only.
Music playback and other interactive 
features are not implemented.
